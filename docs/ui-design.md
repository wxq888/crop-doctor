# UI 设计规范 v1（作物医生 CropDoctor）

> 状态：已定稿 · 与 README.md / architecture.md 同步 · 前端开发以此为准
> 借鉴：同类病害检测系统界面（番茄/茶叶/辣椒系统）、DigiTani 智慧农服、Ant Design / Element Plus / Vant 设计规范

## 1. 设计方向

**一个品牌，两种气质**：双端共享品牌资产，按使用场景差异化。

| | H5 用户端 | PC 管理端 |
|---|---|---|
| 用户 | 农户 / 普通用户 | 管理员 |
| 气质 | 温暖自然、农户友好 | 专业冷静、工具感 |
| 形态 | 竖屏单栏、大圆角、大图标、少文字 | 左导航+工作区、信息密度高、暗色大屏 |
| 组件库 | Vant 4 | Element Plus + ECharts |

## 2. 视觉系统（Design Tokens）

### 2.1 色彩

**品牌主色（双端共享）**

| Token | 值 | 用途 |
|---|---|---|
| `primary` | `#2BA471` | 植物绿：主按钮、选中态、品牌标识 |
| `primary-soft` | `#E8F5EE` | 主色浅底：次级按钮、高亮底、头像底 |

**H5 用户端**

| Token | 值 | 用途 |
|---|---|---|
| `bg` | `#F5F7F6` | 页面底色（微灰绿，护眼） |
| `text` | `#1F2B24` | 主文字 |
| `text-muted` | `#6B7B71` | 辅助文字/时间戳/标签 |

**PC 管理端（暗色）**

| Token | 值 | 用途 |
|---|---|---|
| `bg` | `#0F1419` | 大屏底色 |
| `panel` | `#1A222B` | 卡片/面板 |
| `nav` | `#141C24` | 左侧导航 |
| `text` | `#E4E9EE` | 主文字 |
| `text-muted` | `#7C8A96` | 辅助文字 |

**语义色（承载分级与预警，双端一致）**

| 级别 | 色值 | 用途 |
|---|---|---|
| 无病害 / 正常 | 中性灰 `#6B7B71` | 分级标签 |
| 轻微 / 低风险 | 品牌绿 `#2BA471` | 分级标签、低风险预警 |
| 中等 / 中风险 | 琥珀 `#F5A623` | 分级标签、中风险预警、待处理 |
| 严重 / 高风险 | 红 `#E5534B` | 分级标签、高风险预警、待回复工单 |

### 2.2 字体阶梯（H5 为主）

| 层级 | 字号/字重 | 用途 |
|---|---|---|
| H1 | 22px / 600 | 检测结果主结论（如“番茄晚疫病”） |
| H2 | 17px / 500 | 卡片标题、区块标题 |
| Body | 15px / 400 | 正文、防治方案、对话内容 |
| Caption | 13px / 400 | 辅助信息、置信度 |
| Mini | 12px / 400 | 时间戳、标签 |

PC 端整体字号下调（12-14px 正文），提高信息密度。

### 2.3 圆角与间距

| Token | 值 | 用途 |
|---|---|---|
| 卡片圆角 | 12px | H5 卡片、PC 面板 |
| 按钮圆角 | 20px（胶囊） | H5 主按钮；PC 用 5-6px 小圆角 |
| 气泡圆角 | 12px（非对称：发送方右下 4px） | 问诊对话 |
| 间距基准 | 8 / 12 / 16 / 20 | 卡片内边距 12，区块间距 16-20 |

## 3. H5 用户端设计

### 3.1 导航结构

底部 5 个一级 Tab，中间「问诊」凸出为大圆按钮：

```
 首页      记录       ✚(问诊)      知识库     我的
```

- 凸出按钮：圆形品牌绿底 + 阴影浮起，视觉强调核心 AI 能力
- 选中态：品牌绿 + 加粗

### 3.2 关键页面线框（详见对话中的可视化稿）

| 页面 | 布局要点 |
|---|---|
| **① 首页** | 顶部状态栏 → 预警卡片（琥珀渐变+左色条，可点入预警中心）→ 检测主卡（拍照/相册上传大图区 + 「立即检测」主按钮 + 「摄像头实时检测」次按钮）→ 最近检测一条 |
| **② 检测详情** | 标注图（红框病灶）→ 结论卡（作物·病害名 H1 + 分级标签）→ Grad-CAM 热力图卡（异步加载占位）→ 天气施药提示行 → 「去问诊」主按钮 → 「结果对吗？反馈」次按钮 |
| **③ 智能问诊** | 独立对话页：气泡对话（右绿=用户，左白=AI）→ AI 回答带「引用来源」灰条 → 流式打字光标 → 底部输入栏 + 圆形发送钮 |
| **④ 我的** | 头像卡（圆形头像底 + 昵称 + 身份+检测次数）→ 功能列表（我的检测记录 / 我的反馈[新回复标] / 预警消息[未读标] / 设置 / 关于） |
| **⑤ 记录** | 列表项：缩略图 + 病害名 + 分级标签 + 时间；顶部按病害/时间筛选 |

### 3.3 登录 / 注册页（H5）

**结构**：品牌绿渐变 hero 区（logo + 品牌名 + slogan「拍照识病害 · AI 帮你看田」+ 装饰叶片图形）→ 上圆角白色卡片上浮 → 登录/注册 Tab 切换 → 表单 → 主按钮。

| 元素 | 规范 |
|---|---|
| Hero 区 | 品牌绿渐变 `linear-gradient(160deg, #2BA471 → #1E7A54)`，右侧装饰叶片 emoji/插画，半透明圆形光斑点缀 |
| 卡片上浮 | 白卡 `border-radius: 22px 22px 0 0`，`margin-top: -26px` 压过 hero 下缘 |
| Tab 切换 | 登录/注册并排，选中项加粗 + 底部 3px 品牌绿指示条 |
| 输入框 | 浅灰底 `#F5F7F6`，圆角 12px，左图标 + 占位文字；密码框右侧眼睛切换 |
| 主按钮 | 品牌绿渐变胶囊 `border-radius: 14px`，带柔和投影 `0 6px 16px rgba(43,164,113,0.32)` |
| 辅助 | 「忘记密码？」品牌绿小字；底部协议提示灰字 |
| 注册 | 同框架，增加手机验证码字段（「获取验证码」品牌绿文字按钮） |

设计要点：农户第一印象“亲切可信”，弱化表单压迫感；hero 传递品牌与价值主张，卡片聚焦操作。

### 3.4 H5 交互细节

- 预警卡片：有风险时才显示，无风险时隐藏（首页保持简洁）
- 检测按钮：主操作永远是「立即检测」，绿色胶囊大按钮
- 问诊：支持直接打字（无需先检测）；从检测详情进入时自动携带检测上下文卡片
- 反馈：检测详情底部轻量入口，点击弹出 正确/错误/存疑 三选 + 可选填正确病害名

## 4. PC 管理端设计

### 4.1 整体框架

左侧固定导航（深色 `#141C24`）+ 顶部信息条 + 主工作区。品牌标识置顶（🌱 作物医生，品牌绿）。

### 4.2 登录页（PC 管理端）

**结构**：整页左右分栏——左侧品牌叙事区 + 右侧表单卡片，与监控大屏同一深色体系。

| 区域 | 规范 |
|---|---|
| 左侧品牌区 | 深绿到底色渐变 `linear-gradient(150deg, #123326 → #0F1419)`；顶部 logo（绿底方块 🌱 + 「作物医生 / CROPDOCTOR ADMIN」）；下方大标题「农作物病害 **智能检测与问诊** 管理平台」（关键词品牌绿高亮）+ 副标题（技术能力说明）+ 功能胶囊标签（📊实时监控 ⚠预警中心 💬工单答疑）；背景放射光斑点缀 |
| 右侧表单区 | 深面板 `#141C24`；标题「管理员登录」+ 副标题；账号/密码字段（深底 `#0F1419` + 细边框，聚焦时边框变品牌绿）；「记住我」复选 + 「忘记密码？」；主按钮品牌绿渐变 |
| 底部 | 「仅限授权管理员访问 · 操作将被记录」灰色小字，传递安全严肃感 |

设计要点：与 H5 的“亲切”形成对比，PC 登录页传递“专业、可信、安全”；管理员无注册入口（账号由系统预置/分配）。

### 4.3 关键页面线框

| 页面 | 布局要点 |
|---|---|
| **⑤ 实时监控大屏** | 顶部 4 个统计卡（今日检测/准确率[绿]/预警中[琥珀]/待回复工单[红]）→ 左：检测量趋势 ECharts 柱状图 → 右：实时事件流（彩色圆点分类：绿=检测 红=预警 琥珀=工单，「● LIVE」标记，WebSocket 滚动） |
| **⑥ 反馈工单中心** | 左：工单列表（待回复置顶，显示编号/用户/摘要/类型/时间）→ 右：对话式回复界面（用户消息左灰 / 管理员回复右绿）+ 底部回复输入框；检测反馈类工单可查看附图与样本 |
| **预警中心** | 病害-气象规则配置表（病害/温度区间/湿度区间/降雨条件/风险等级/防治建议/启用开关）→ 当前风险总览 → 预警记录与推送情况 |
| **用户管理** | 用户列表 → 用户详情抽屉（其检测记录/反馈历史/预警记录）→ 禁用启用 / 重置密码 |
| **检测记录管理** | 全局记录表格（图缩略/用户/病害/分级/置信度/时间/反馈状态）→ 详情侧滑（含热力图） |
| **知识库管理** | 文档列表 + 上传/编辑 + 向量化状态标记 |
| **模型管理** | 权重版本列表 + 当前生效标记 + 上传切换 |

### 4.3 PC 交互细节

- 监控大屏默认暗色，适合常开展示；提供亮色切换（答辩投影用）
- 实时事件流自动滚动，新事件从顶部插入
- 工单中心待回复数在导航上挂角标
- 所有表格支持筛选 + 导出（答辩演示可现场导数据）

## 6. 无障碍与边界

- 关键文字对比度 ≥ 4.5:1（H5 浅底深字 / PC 深底浅字均满足）
- 分级/预警不只依赖颜色：标签带文字（轻微/中等/严重），预警带图标 ⚠
- 空状态：无检测记录/无预警/无工单时给出引导插画位 + 操作按钮
- 加载态：检测推理、热力图生成、问诊流式均有 loading 反馈
- H5 适老化倾向：大按钮、大字号、少层级（农户用户）
